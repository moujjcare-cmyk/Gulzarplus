# 🌹 گلزار سمارٹ ہوم گارڈن (GULZAR Smart Home Garden — MOUJ SYNC Edition)

**پیشکش و کنٹرولڈ بائے: موج سِنک (Powered & Controlled by MOUJ SYNC)**

## 📦 اس پیکج میں شامل فائلیں:
1. **`index.html`**: مکمل اپڈیٹ شدہ گلزار ایپ (سرخ گلاب آئیکن، موج سِنک فوٹر، جیمنائی انسائیکلوپیڈیا پرامپٹ و پیسٹ باکس، انٹرایکٹو پانی/گوڈی/کٹائی موڈل، شیڈول الرٹ، اور محفوظ گٹ ہب سنک کے ساتھ)۔
2. **`icon-192.png` اور `icon-512.png`**: آپ کے سرخ گلاب والا آفیشل گلزار ایپ آئیکن۔
3. **`.github/workflows/build-apk.yml`**: گٹ ہب ایکشنز سے خودکار اینڈرائیڈ APK بنانے کی فائل (جو گلاب آئیکن خودکار طور پر APK پر لگا دیتی ہے)۔
4. **`manifest.json`، `sw.js`، `package.json`، `capacitor.config.json`**: پی ڈبلیو اے (PWA) اور کیپیسٹر (Capacitor) کنفیگریشن فائلیں۔

## 🚀 گٹ ہب پر اپڈیٹ اور APK بنانے کا طریقہ:
1. اپنی گٹ ہب ریپوزٹری (`Gulzar-Revamp-`) میں `index.html`، `icon-192.png`، `icon-512.png` اور `.github/workflows/build-apk.yml` اپلوڈ کر کے **Commit** کریں۔
2. جیسے ہی آپ `index.html` اپڈیٹ کریں گے، **Actions** ٹیب میں نیا APK خودکار بن جائے گا اور آپ کا پرانا ڈیٹا (`gulzar-database.json`) 100% محفوظ رہے گا۔
